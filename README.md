# نظام إدارة مراكز التدريب (مواعيد التدريب، التسجيل، التقييم)
==========================

### ملخص المشروع

نظام إدارة مراكز التدريب هو تطبيق إلكتروني يهدف إلى تسهيل إدارة مراكز التدريب من خلال إدارة مواعيد التدريب، تسجيل الأفراد، وتقييم أدائهم. يهدف المشروع إلى توفير بيئة إدارية فعالة ومستدامة.

### هيكلية المشروع

* `app/`: مجلد تطبيق Node.js
 + `controllers/`: مجلد التحكم بالبيانات
 + `models/`: مجلد النماذج
 + `routes/`: مجلد الطرق
 + `services/`: مجلد الخدمات
* `docker/`: مجلد تكوين Docker
 + `docker-compose.yml`: ملف تكوين Docker Compose
 + `Dockerfile`: ملف تكوين Docker
* `db/`: مجلد قاعدة البيانات
 + `schema.sql`: ملف تكوين قاعدة البيانات
* `tests/`: مجلد الاختبارات

### إعداد البيئة باستخدام Docker Compose

1. تأكد من وجود Docker و Docker Compose على جهازك.
2. افتح مجلد المشروع في المتصفح.
3. استخدم الأمر التالي لتشغيل البيئة باستخدام Docker Compose:
bash
docker-compose up -d

4. بعد تشغيل البيئة، استخدم الأمر التالي لتشغيل قاعدة البيانات:
bash
docker-compose exec db psql -U postgres

5. استخدم الأمر التالي لتشغيل تطبيق Node.js:
bash
docker-compose exec app npm start

6. افتح متصفحك واكتب `http://localhost:3000` لتشغيل التطبيق.

### وحدات المشروع

* **Modules**:
 + `TrainingCenter`: وحدة إدارة مراكز التدريب
 + `TrainingSchedule`: وحدة إدارة مواعيد التدريب
 + `Registration`: وحدة تسجيل الأفراد
 + `Evaluation`: وحدة تقييم أداء الأفراد
* **Tables**:
 + `trainings`: جدول إدارة التدريبات
 + `schedules`: جدول إدارة مواعيد التدريب
 + `registrations`: جدول تسجيل الأفراد
 + `evaluations`: جدول تقييم أداء الأفراد
* **Roles**:
 + `admin`: دور الإدارة
 + `trainer`: دور المدرب
 + `trainee`: دور المتدرب
